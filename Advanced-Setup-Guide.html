Invoice Studio - Advanced Setup Guide

Advanced mode is optional. Basic email sending works without Google OAuth. Advanced mode is only for Drive upload + auto Google Sheets logging.

1) EmailJS Setup

  • Free signup: https://dashboard.emailjs.com/sign-up
  • Public Key: https://dashboard.emailjs.com/admin/account
  • Service ID: https://dashboard.emailjs.com/admin
  • Template ID: https://dashboard.emailjs.com/admin/templates
  • YouTube (EmailJS): https://www.youtube.com/results?search_query=emailjs+setup+tutorial

2) Google OAuth (Advanced Optional)

  • Google Cloud Credentials: https://console.cloud.google.com/apis/credentials
  • Enable APIs: Google Drive API and Google Sheets API
  • Create OAuth Client ID (Web application)
  • Authorized JavaScript origins:
  • http://127.0.0.1:5500
  • http://localhost:5500
  • YouTube (Google Auth): https://youtube.com/shorts/WABhO9KsOpU?si=CquIKKTmJXUtGLi-

3) In-App Advanced Testing

  • Open Email send setup (EmailJS)
  • Paste your Google OAuth Client ID
  • Use TEST UPLOAD (testing only) to drop files
  • Click Send Test Email

4) Live Send Behavior

  • Send Invoice uploads task attachments to Drive (if advanced is configured)
  • App logs each live transaction to one Google Sheet automatically
  • If advanced is not configured, email still sends, but Drive/Sheets features are skipped
